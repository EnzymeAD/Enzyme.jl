## Unreleased

### Added

- `EnzymeCore.TypeEgal{T}` is the type of the type value `T` in an annotation. It is `Core.TypeEgal{T}` on Julia 1.14 and later, and `Type{T}` on earlier versions [#4086].

### Changed

- On Julia 1.14, `Const(T)` for a type `T` is a `Const{Core.TypeEgal{T}}`. A rule method with a `::Const{Type{T}}` argument does not apply to it. Use `::Const{EnzymeCore.TypeEgal{T}}`, which is correct on all supported Julia versions [#4086].
