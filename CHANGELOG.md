# Enzyme release notes

All notable changes to Enzyme.jl are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

EnzymeCore.jl and EnzymeTestUtils.jl have their own release notes: [EnzymeCore](https://github.com/EnzymeAD/Enzyme.jl/blob/main/lib/EnzymeCore/CHANGELOG.md) and [EnzymeTestUtils](https://github.com/EnzymeAD/Enzyme.jl/blob/main/lib/EnzymeTestUtils/CHANGELOG.md).

For releases up to and including v0.13.221, see the [GitHub releases](https://github.com/EnzymeAD/Enzyme.jl/releases).

## Unreleased

### Changed

- The minimum version of Enzyme_jll is 0.0.311 [#3765].
- The minimum version of GPUCompiler on the 2.x line is 2.23. GPUCompiler 1.x from 1.23.1 is still supported [#4105].
- The minimum version of LLVM.jl is 10.5.2 [#4077], [#4078].

### Fixed

- A crash during garbage collection on Julia 1.12 and later. The return roots of a thunk call were not initialized [#4069].
- Very long compile times for functions with many basic blocks, for example large KernelAbstractions kernels. SimplifyCFG now runs before each run of the always-inliner [#4050].
- Julia 1.14: custom rules were not used, because inference inlined the function into its caller. The rewrites of broadcast, FunctionWrappers, `unsafe_copyto!`, `within_autodiff` and `invoke` did not run either [#3344].
- Julia 1.14: a `CallingConventionMismatchError` for custom rules [#4080].
- Julia 1.14: the errors `duplicate definition of symbol` and `Symbols not found` from the JIT. Each thunk now has its own JITDylib [#4078].
- Julia 1.14: differentiation of `Memory` allocations (`julia.gc_alloc_memory`) [#4081].
- Julia 1.14: support for the field-aware write barriers [#3765].
- Julia 1.14: a segmentation fault in `Enzyme.Compiler.enzyme_code_llvm` [#4097].
- Julia 1.14: the lookup of the CHOLMOD struct types of SparseArrays [#4075].
- LLVM 21 and later: the error `Unknown attribute kind: nocapture` [#4076].
- LLVM 21 and later: an assertion failure when Enzyme imports a cached autodiff thunk [#4079].
- LLVM 22: the new form of the lifetime intrinsics [#4077].
